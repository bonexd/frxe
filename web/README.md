# Vitr Web

Vitr Web is the browser version of Vitr.

Current version: **0.1.0**.

## Source layout

- `src/` — React player and landing UI.
- `api/` — serverless API implementation.
- `server/` and `shared/` — shared server/application logic.
- `public/` — public assets, including the Vitr icon.
- `tests/` — unit and browser tests.
- `scripts/` — validation and source metadata tooling.

Run `npm install`, then `npm run dev` for local development or `npm run check` for validation.
